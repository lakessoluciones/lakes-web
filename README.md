# lakes-web

Sitio de Lakes Soluciones. HTML estático, sin build: se publica tal cual (Cloudflare Pages, carpeta raíz `/`).

- `index.html`: la página. Estilo según el Design.md del brand kit (sección 12, layout editorial).
- WhatsApp: el botón aparece solo al poner el número en la constante `WHATSAPP` al final de `index.html` (formato `569XXXXXXXX`).
- SEO: `robots.txt`, `sitemap.xml`, `og.png` (imagen al compartir), datos JSON-LD en el `<head>`. Las URLs apuntan a `https://lakessoluciones.cl/`.
